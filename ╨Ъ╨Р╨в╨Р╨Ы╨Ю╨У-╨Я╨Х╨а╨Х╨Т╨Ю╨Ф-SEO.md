# Каталог, переводы и продвижение сайта

Короткая памятка по тому, что изменилось, и что нужно настроить перед публикацией.

---

## 1. Языки

Сайт работает на **5 языках**: русский, узбекский, английский, китайский, арабский.

Убраны: немецкий, белорусский, казахский, украинский. При первом запуске сервер сам
удаляет их из базы — ничего делать не нужно.

**Как добавить или убрать язык:**

1. `server/src/seed-content.js` → строка `export const LANGS = [...]`
2. `site-client/src/app/i18n/locales.ts` → массив `LANGUAGES` и словарь `dict`
3. `admin-panel/src/ContentEditor.tsx` → `LANG_NAMES`
4. `site-client/scripts/prerender.mjs` → `LANG_META`

Перезапустить сервер. Новый язык заполнится переводом автоматически.

## 2. Перевод

### Почему раньше переводило не везде

Бесплатный переводчик Google при большом объёме упирается в ограничение по
частоте запросов и молча возвращает исходный текст. Раньше такие строки просто
оставались на русском, и никто об этом не узнавал.

Что исправлено:

1. **Проверка полноты.** После перевода сервер сам проверяет: если в результате
   остались русские буквы, а целевой язык кириллицей не пишется — строка не
   перевелась. Такие строки переспрашиваются заново, до трёх заходов, мелкими
   порциями и с паузами.
2. **Честный отчёт.** В админ-панели рядом с каждым языком видно, сколько строк
   осталось непереведёнными. Зелёная плашка — переведено всё, оранжевая с
   числом — осталось столько-то.
3. **Кнопка «Допереводить».** Появляется, когда есть что доперевести. Переводит
   только оставшееся, ручные правки не трогает. Можно нажимать сколько угодно раз.
4. **Закрыты пропуски.** Часть полей вообще не попадала в перевод — например,
   «Цена по запросу» на каждой карточке, цифры результатов и названия
   сертификатов. Теперь переводится весь текст сайта без исключений.

### Как это работает сейчас

По умолчанию включён бесплатный переводчик Google — работает сразу, без ключей,
но переводит дословно и на большом объёме часть строк может не осилить.

### Как включить грамотный перевод

Смысловой переводчик понимает, что это сайт про системы контроля дорожного движения,
знает отраслевые термины и различает, где заголовок, а где строка техпаспорта.

1. Получите ключ на https://console.anthropic.com
2. Задайте переменную окружения сервера:

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. Перезапустите сервер.

Больше ничего менять не нужно — переводчик переключится сам. В админ-панели
появится отметка «Смысловой перевод». Если ключа нет или сервис не ответил,
сервер молча вернётся к бесплатному Google — сайт не сломается.

**Со смысловым переводчиком проблема неполного перевода уходит:** запросов
нужно в десятки раз меньше (строки идут пачками по 25), ограничение по частоте
не срабатывает, и текст получается грамотным, а не подстрочником.

### Если переводит не всё

Раньше переводчик был один. Если он не отвечал — а Google блокирует запросы
с адресов дата-центров, и на боевом хостинге это происходит часто, — строка
молча оставалась на русском. Отсюда и «переводит не везде».

Теперь работает **цепочка переводчиков**: строки, которые не осилил первый,
передаются следующему.

```
claude  →  google-free  →  mymemory      (если задан ANTHROPIC_API_KEY)
google-free  →  mymemory                 (по умолчанию)
```

Плюс к этому:

- перевод **проверяется**: если в результате остался русский текст, а целевой
  язык кириллицей не пишется — строка считается непереведённой и уходит на
  повтор, а не остаётся как есть;
- в консоли сервера видно, сколько строк не прошло и через какие службы;
- в админ-панели у каждого языка показано число непереведённых строк
  и кнопка **«Дозаполнить»** — переводит только их, ручные переводы не трогает.

Если непереведённых строк много и они не убывают — значит с сервера
недоступны обе бесплатные службы. Решение: задать `ANTHROPIC_API_KEY`
(смысловой перевод работает по обычному HTTPS и не блокируется).

**MyMemory** — бесплатный запасной переводчик без ключа, около 5000 слов
в сутки с одного адреса. Для правок содержимого достаточно; для перевода
всего сайта целиком нужен ключ.

### Защита названий

Названия приборов, аббревиатуры и единицы измерения **не переводятся никогда**,
при любом переводчике. Раньше «W Space-S» мог стать «В Космос-С», а «IP68» — «ИП68».

Список защищённых терминов: `server/src/glossary.js` → массив `PROTECTED`.
**Добавляйте туда каждое новое название прибора.**

Там же отраслевой словарь `GLOSSARY` — как правильно переводить термины
(комплекс → system, а не complex; постановление → penalty notice, а не resolution).

## 3. Каталог комплексов

Каталог стоит **на месте бывшего технического паспорта** — справа от продающего
текста на странице решения. Клиент читает текст и сразу видит, чем задача
закрывается. Нажатие на карточку открывает полную характеристику с техпаспортом
и фотографиями; фото раскрывается на весь экран. Цены нет нигде — только
«Цена по запросу».

### У каждого решения свои приборы

Комплексы не повторяются между решениями. Всего 24 прибора, по 3 на решение:

| Решение | Комплексы |
|---|---|
| Превышение скорости | W Space-S, URALAN-P, W Space-A |
| Проезд на красный | TRC-Cross, TRC-Phase, TRC-Vision |
| Незаконная парковка | PARKON-S, PARKON-M, PARKON-Z |
| Остановка запрещена | STOPLINE-S, STOPLINE-M, STOPLINE-G |
| Выделенная полоса | BUSLINE-A, BUSLINE-S, BUSLINE-M |
| Ж/д переезд | RAILGUARD-C, RAILGUARD-S, RAILGUARD-M |
| Телефон за рулём | DRIVERCAM-S, DRIVERCAM-M, DRIVERCAM-G |
| Ремни безопасности | BELTCAM-S, BELTCAM-M, BELTCAM-G |

Названия и характеристики — рабочие заготовки. Замените их на реальные модели.

### Как редактировать

Админ-панель → **Редактор сайта** → **Проблемы** → раскрыть проблему →
раздел **Каталог комплексов**. Там можно добавить комплекс, удалить, поменять
местами, загрузить фотографии, заполнить техпаспорт и возможности.

### ⚠️ При переименовании прибора

Впишите новое название в `server/src/glossary.js` → массив `PROTECTED`,
**иначе переводчик переведёт его как обычное слово** («BELTCAM» может стать
«РЕМЕНЬКАМЕРА»). Длинные названия ставьте выше коротких.

### Фотографии

Сейчас стоят схематичные заготовки (`site-client/public/devices/`, 72 файла).
**Замените их на реальные фотографии через админ-панель** — это заметно
поднимет доверие к каталогу.

### Начальное наполнение

`server/src/seed-devices.js` — используется только при первом запуске, когда
базы ещё нет. После правки этого файла выполните из папки `site-client`:

```
npm run sync:devices
```

Это обновит запасные данные, которые сайт показывает при недоступном сервере.

## 4. Продвижение и превью ссылок

### Что было не так

Сайт был закрыт от поисковиков тегом `noindex`, все страницы жили по одному
адресу `/`, и у любой ссылки было одинаковое пустое превью. Для деловой
переписки это критично: отправляете ссылку в Telegram — собеседник видит
пустой прямоугольник.

### Что сделано

**Адреса.** У каждой страницы теперь свой адрес:

```
/ru/                                  главная на русском
/en/solutions/solution-speeding       решение на английском
/ar/solutions/solution-parking        решение на арабском
```

Ссылку можно скопировать и отправить — откроется нужная страница на нужном языке.
Работают кнопки «назад» и «вперёд» в браузере.

**Готовые HTML-страницы.** Мессенджеры и поисковые роботы не выполняют
JavaScript — они читают теги прямо из HTML. Поэтому при сборке создаётся
по отдельному HTML-файлу на каждую страницу и каждый язык (45 файлов):
со своим заголовком, описанием, картинкой превью и текстом страницы внутри.

**Индексация открыта**, добавлены `sitemap.xml` и `robots.txt`.

### Что настроить перед публикацией

В настройках Netlify (или в переменных окружения сборки) задайте:

```
VITE_SITE_URL = https://вашдомен.com      ← адрес самого сайта
VITE_API_URL  = https://api.вашдомен.com  ← адрес сервера
```

`VITE_SITE_URL` обязателен: без него в ссылках превью и в `sitemap.xml`
останется `https://olanhightech.com`.

Если задан `VITE_API_URL`, при сборке в готовые страницы попадут актуальные
тексты из админ-панели. **После крупных правок содержимого пересоберите сайт** —
иначе поисковики и превью ссылок будут показывать старую версию.

### Картинка превью

`site-client/public/og-image.png`, размер 1200×630. Показывается при отправке
ссылки в Telegram, WhatsApp, LinkedIn и почте. Замените на фотографию реального
комплекса, если нужно.

### Проверить превью после публикации

- Telegram — просто отправьте ссылку самому себе
- Facebook / LinkedIn — https://developers.facebook.com/tools/debug/
- Разметка Schema.org — https://search.google.com/test/rich-results

### Отправить сайт в поиск

После публикации добавьте домен в Google Search Console и Яндекс.Вебмастер
и укажите там адрес карты сайта: `https://вашдомен.com/sitemap.xml`
