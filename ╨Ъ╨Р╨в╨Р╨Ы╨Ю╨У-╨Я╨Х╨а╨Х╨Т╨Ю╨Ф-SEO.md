# Каталог, переводы и продвижение сайта

Короткая памятка по тому, что изменилось, и что нужно настроить перед публикацией.

---

## 1. Языки

Сайт работает на **5 языках**: русский, узбекский, английский, китайский, арабский.

Убраны: немецкий, белорусский, казахский, украинский. При первом запуске сервер сам
удаляет их из базы — ничего делать не нужно.

**Как добавить или убрать язык:**

1. `server/src/seed-content.js` → строка `export const LANGS = [...]`
2. `site-client/src/app/i18n/locales.ts` → массив `LANGUAGES` и словарь `dict`
3. `admin-panel/src/ContentEditor.tsx` → `LANG_NAMES`
4. `site-client/scripts/prerender.mjs` → `LANG_META`

Перезапустить сервер. Новый язык заполнится переводом автоматически.

## 2. Перевод

### Как это работает сейчас

По умолчанию включён бесплатный переводчик Google — работает сразу, без ключей,
но переводит дословно.

### Как включить грамотный перевод

Смысловой переводчик понимает, что это сайт про системы контроля дорожного движения,
знает отраслевые термины и различает, где заголовок, а где строка техпаспорта.

1. Получите ключ на https://console.anthropic.com
2. Задайте переменную окружения сервера:

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. Перезапустите сервер.

Больше ничего менять не нужно — переводчик переключится сам. В админ-панели
появится отметка «Смысловой перевод». Если ключа нет или сервис не ответил,
сервер молча вернётся к бесплатному Google — сайт не сломается.

### Защита названий

Названия приборов, аббревиатуры и единицы измерения **не переводятся никогда**,
при любом переводчике. Раньше «W Space-S» мог стать «В Космос-С», а «IP68» — «ИП68».

Список защищённых терминов: `server/src/glossary.js` → массив `PROTECTED`.
**Добавляйте туда каждое новое название прибора.**

Там же отраслевой словарь `GLOSSARY` — как правильно переводить термины
(комплекс → system, а не complex; постановление → penalty notice, а не resolution).

## 3. Каталог комплексов

На странице каждого решения вместо одиночного техпаспорта — каталог приборов.
Клиент нажимает на карточку и видит полную характеристику с фотографиями.
Фото открывается на весь экран. Цены нет нигде — только «Цена по запросу».

### Как редактировать

Админ-панель → **Редактор сайта** → **Проблемы** → раскрыть проблему →
раздел **Каталог комплексов**.

Там можно: добавить комплекс, удалить, поменять местами, загрузить фотографии,
заполнить техпаспорт и возможности.

Изменения расходятся по всем языкам при сохранении.

### Начальное наполнение

Файл `server/src/seed-devices.js` — используется только при первом запуске,
когда базы ещё нет. Дальше всё правится в панели.

После правки этого файла выполните из папки `site-client`:

```
npm run sync:devices
```

Это обновит запасные данные, которые сайт показывает, если сервер недоступен.

### Фотографии

Сейчас стоят схематичные изображения-заготовки (`site-client/public/devices/`).
**Замените их на реальные фотографии приборов через админ-панель** —
это заметно поднимет доверие к каталогу.

## 4. Продвижение и превью ссылок

### Что было не так

Сайт был закрыт от поисковиков тегом `noindex`, все страницы жили по одному
адресу `/`, и у любой ссылки было одинаковое пустое превью. Для деловой
переписки это критично: отправляете ссылку в Telegram — собеседник видит
пустой прямоугольник.

### Что сделано

**Адреса.** У каждой страницы теперь свой адрес:

```
/ru/                                  главная на русском
/en/solutions/solution-speeding       решение на английском
/ar/solutions/solution-parking        решение на арабском
```

Ссылку можно скопировать и отправить — откроется нужная страница на нужном языке.
Работают кнопки «назад» и «вперёд» в браузере.

**Готовые HTML-страницы.** Мессенджеры и поисковые роботы не выполняют
JavaScript — они читают теги прямо из HTML. Поэтому при сборке создаётся
по отдельному HTML-файлу на каждую страницу и каждый язык (45 файлов):
со своим заголовком, описанием, картинкой превью и текстом страницы внутри.

**Индексация открыта**, добавлены `sitemap.xml` и `robots.txt`.

### Что настроить перед публикацией

В настройках Netlify (или в переменных окружения сборки) задайте:

```
VITE_SITE_URL = https://вашдомен.com      ← адрес самого сайта
VITE_API_URL  = https://api.вашдомен.com  ← адрес сервера
```

`VITE_SITE_URL` обязателен: без него в ссылках превью и в `sitemap.xml`
останется `https://olanhightech.com`.

Если задан `VITE_API_URL`, при сборке в готовые страницы попадут актуальные
тексты из админ-панели. **После крупных правок содержимого пересоберите сайт** —
иначе поисковики и превью ссылок будут показывать старую версию.

### Картинка превью

`site-client/public/og-image.png`, размер 1200×630. Показывается при отправке
ссылки в Telegram, WhatsApp, LinkedIn и почте. Замените на фотографию реального
комплекса, если нужно.

### Проверить превью после публикации

- Telegram — просто отправьте ссылку самому себе
- Facebook / LinkedIn — https://developers.facebook.com/tools/debug/
- Разметка Schema.org — https://search.google.com/test/rich-results

### Отправить сайт в поиск

После публикации добавьте домен в Google Search Console и Яндекс.Вебмастер
и укажите там адрес карты сайта: `https://вашдомен.com/sitemap.xml`
