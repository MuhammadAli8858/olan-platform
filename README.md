# OLAN HIGH TECH — платформа из трёх сайтов

Единая система: главный сайт с онлайн-чатом, кабинеты сотрудников и админ-панель.
Все три приложения работают с одним сервером.

## Быстрый старт

**Шаг 1. Установить зависимости** (один раз, нужен Node.js 18+):

```
./install-all.sh        # Linux / macOS
install-all.bat         # Windows
```

**Шаг 2. Запустить всё:**

```
./start-all.sh          # Linux / macOS
start-all.bat           # Windows
```

Откроются четыре адреса:

| Что | Адрес |
|-----|-------|
| Главный сайт (для клиентов) | http://localhost:5173 |
| Кабинеты операторов и менеджеров | http://localhost:5174 |
| Админ-панель | http://localhost:5175 |
| Сервер (API и чат) | http://localhost:4000 |

## Вход в систему

### Администратор

Логин и пароль задаются **в коде** — файл `server/src/config.js`:

```js
export const ADMIN = {
  email: "admin@olanhightech.com",
  password: "OlanAdmin2026!",   // ⚠️ ОБЯЗАТЕЛЬНО поменяйте!
};
```

Вход: http://localhost:5175

### Менеджер

Создаётся администратором в админ-панели → «Менеджеры и операторы» → «Добавить менеджера».
Там же админ задаёт ему логин (почту) и пароль.

Вход: http://localhost:5174

### Оператор

Создаётся менеджером в его кабинете (или админом в панели).
Менеджер указывает имя и почту оператора, а **пароль задаёт сам** — так доступ остаётся под его контролем.

Вход: http://localhost:5174

## Первый запуск: что сделать по порядку

1. Откройте админ-панель, войдите с логином из `config.js`
2. Перейдите на «Менеджеры и операторы» → добавьте менеджера
3. Раскройте карточку менеджера → «Оператор» → добавьте одного-двух операторов
4. Откройте кабинет (:5174) в другом окне, войдите оператором
5. Откройте главный сайт (:5173), напишите в чат внизу справа
6. Сообщение появится у оператора; его ответ вернётся в чат на сайте

## Как работает онлайн-чат

* У каждого посетителя **свой отдельный диалог** — номер сессии хранится в его браузере,
  переписка не теряется при перезагрузке страницы.
* Новый диалог **случайно назначается** одному из операторов, находящихся на смене.
  Если онлайн никого нет — обращение всё равно сохраняется и достаётся оператору, когда он войдёт.
* Оператор видит и отвечает **только в своих диалогах**.
* Заявки с формы «Запросить бесплатную консультацию» распределяются так же — случайно между операторами.
* **Уведомления браузера** работают с обеих сторон: посетителю приходит уведомление об ответе оператора,
  оператору — о новом сообщении и новой заявке. Разрешение запрашивается при первом открытии чата
  (и кнопкой в кабинете оператора).

## Что редактируется в админ-панели

Раздел «Редактор сайта» — **без единой строчки кода**:

| Раздел | Что можно менять |
|--------|------------------|
| Компания | Название, слоган, телефон, почта, адрес, описание |
| Главный экран | Заголовки и подводка первого экрана |
| Проблемы и решения | Добавить/изменить/удалить проблему вместе со всей страницей решения: тексты, факты, продукт, преимущества, техпаспорт, результаты, призыв |
| География | Страны на карте (по ISO-коду) и города-маркеры |
| Проекты | Реализованные кейсы: страна, город, описание, показатели |
| Партнёры | Логотип (загрузка файла), название, направление, описание |
| Цифры и этапы | Полоса цифр, этапы внедрения, лента фиксаций, сертификаты |

Везде есть кнопка **удаления** — если что-то добавили по ошибке.

Раздел «Менеджеры и операторы»:
* видно всех менеджеров и привязанных к ним операторов;
* рядом с именем оператора **цифры**: сколько диалогов, сообщений и заявок ему пришло;
* кнопки добавления менеджера, добавления оператора, смены пароля и удаления.

## Перевод сайта на 9 языков

**Одна команда переводит весь сайт** (все тексты, включая длинные страницы решений):

```
cd server
npm run translate
```

Используется бесплатный переводчик Google — без ключей и регистрации,
нужен только интернет. Перевод ~400 полей на 8 языков занимает несколько минут.

После этого **любая правка в админ-панели переводится автоматически**
при сохранении: меняется только изменённое поле, ручные переводы
не затираются. Кнопка «Перевести всё заново» в админке делает то же,
что и команда.

## Языки сайта

Сайт переключается между **9 языками**: русский, узбекский, английский, китайский,
немецкий, белорусский, арабский (справа налево), казахский, украинский.

* **Надписи интерфейса** (меню, кнопки, заголовки секций, форма, чат) переведены на все 9 языков —
  файл `site-client/src/app/i18n/locales.ts`.
* **Содержимое сайта** (тексты проблем, решений, проектов) заполнено по-русски.
  Для остальных языков в админ-панели выберите язык → «Скопировать из русского» → переведите тексты.
  Пока перевода нет, сайт показывает русскую версию — страница никогда не будет пустой.

## Публикация на реальном сервере

Перед выкладкой в интернет обязательно:

1. **Смените логин и пароль администратора** в `server/src/config.js`
2. **Смените `JWT_SECRET`** там же на длинную случайную строку
3. Укажите адрес сервера в трёх файлах (или через переменную `VITE_API_URL`):
   * `site-client/src/app/config.ts`
   * `portal-staff/src/lib.ts`
   * `admin-panel/src/lib.ts`
4. Включите **HTTPS** — уведомления браузера работают только по защищённому соединению
   (на `localhost` работают и без него)
5. Для серьёзной нагрузки замените файловое хранилище `server/src/db.js` на PostgreSQL или MongoDB —
   интерфейс функций останется тем же
6. Настройте регулярное резервное копирование файла `server/data/db.json` и папки `server/uploads/`

Сборка для публикации:

```
cd site-client   && npm run build    # результат в dist/
cd portal-staff  && npm run build
cd admin-panel   && npm run build
```

## Возможные вопросы

**Сайт открылся, но тексты старые / чат не подключается.**
Не запущен сервер. Проверьте, что `server` работает на порту 4000.
Главный сайт продолжит работать и без сервера — покажет встроенные тексты, но без чата.

**Уведомления не приходят.**
Проверьте, что разрешение выдано (значок замка в адресной строке) и что вкладка не активна —
браузеры не показывают уведомления для вкладки, на которую вы сейчас смотрите.

**Сообщение оператора не дошло до посетителя.**
Убедитесь, что посетитель не закрыл вкладку — история сохраняется и будет показана,
когда он вернётся на сайт с тем же браузером.
